# my-portfolio

Сайт-портфоліо Альони, UI/UX-дизайнерки. План сайту — у файлі [План сайту-портфоліо.md](./План%20сайту-портфоліо.md).

## Запуск локально

```bash
npm install
npm run dev
```

## Збірка

```bash
npm run build
```

Результат збирається в теку `dist/`. Vercel визначає Vite автоматично (Build Command: `npm run build`, Output: `dist`).
